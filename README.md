# 農產品比價網

使用原生 JavaScript 串接農產品交易行情 API 並呈現資料表。

[線上 Demo](https://hthoftt.github.io/js-api/)

![農產品比價網：蔬菜類行情表](./docs/screenshot.jpg)

## 功能
- 依類別篩選:蔬菜、水果、花卉
- 以作物名稱搜尋
- 排序:上價、中價、下價、平均價、交易量
- 資料欄位:名稱、市場、上價、中價、下價、平均價、交易量
